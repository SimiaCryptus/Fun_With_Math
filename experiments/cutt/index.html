Coupled Uncertain Theory Trees

interactive demonstrator · fixed-tree core (§5.1–5.7)
What am I looking at?

Each observation is a box (where the point could be) with a set of allowed labels. A master tree cuts each box into fragments. The algorithm then:

  1. Contracts boxes using hard anchor evidence (floor, geometry).
  2. Distributes mass over the surviving fragments (height, soft).
  3. Challenges that answer with near-equally-good alternative theories.
  4. Bounds each fragment's mass, then classifies what is known and what is not.

Firewall: things on the floor are hard knowledge. Things above it are preferences. Soft quantities never become hard ones.
