Residual-Volume Coding Lab

A decision tree scored in bits: each leaf is a region, and a point costs name the leaf + log₂(leaf volume / resolution cell). A split pays off only when the share of points on each side differs from the share of space — and only if that gain exceeds the cost of describing the boundary.

Generators only propose geometry; the code length decides. tightBox trims empty margin (defensive baseline), axis is the density-tree family, affinePCA finds planes, quadEllipsoid finds ellipsoids/shells, quadImplicit fits an algebraic law g(x) ≈ 0.

          ledger
          

            Blue = what the model actually costs per point (leaf name +
            residual address). Amber = model description amortised per
            training point. Grey = the 30-bit no-model reference. Shorter is
            better; a model that cannot beat grey is worthless.

          race
          

            One bar per candidate split, showing its certified gain
            interval [G⁻, G⁺]. Geometry is refined only where the
            intervals still overlap, so the winner is certified as cheaply as
            possible. Bars left of the zero line cannot pay for themselves.
          

          
        


        

          profile (codim & scale)
          

            Each line is one root-to-leaf path: cumulative bits spent on
            boundaries (x) against cumulative log₂ volume removed (y). A few
            big cheap drops then a plateau means structure was collapsed;
            many small break-even steps mean the model is just tiling a
            diffuse density.
