Welcome

Static Secrets is an encrypted browser proxy. Paste a URL to an encrypted .ssec blob above and press Load. The app fetches it, tries your stored keychain passwords, and renders the decrypted HTML, Markdown, or binary download — all client-side.

Encrypt files with the CLI:
node tools/encrypt.js input.md --out secret.ssec

Manage stored passwords via the Keychain button.
